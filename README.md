# FEEL by Roisin website package

- `index.html`: website entry point.
- `assets/images/`: page imagery and video poster images.
- `assets/videos/`: homepage video and locally downloaded About video (when source download is available).
- `assets/logos/`: logo SVGs.
- `assets/icons/`: favicon assets.
- `assets/testimonials/`: six supplied testimonial photos.

Contact form submissions are configured to use FormSubmit AJAX for niallcorcoran2@gmail.com. FormSubmit may require a one-time email confirmation before delivery begins. A static HTML site cannot securely send email by itself; this relies on the third-party form service.

Open `index.html` in a browser to preview. External fonts and Tailwind CDN styling may require internet access.

Typography update: The shared “Ready to begin?” CTA now uses the existing site eyebrow, headline, body-copy and button sizing. “FEEL heals” is italicised to match the requested hierarchy.
